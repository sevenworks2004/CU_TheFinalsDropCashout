# Casualties Unknown The Finals Drop Cashout
![Preview](docs/images/expie_finals.png)

## Requirements

Before installing the mod, make sure you have the following dependencies installed:

### BepInEx

Install **BepInEx** using the official modding guide:

- [Casualties Unknown Modding Guide](https://casualtiesunknown.miraheze.org/wiki/Modding)

### CUCoreLib

**CUCoreLib is required** for this mod.

Download and install the latest compatible release:

- [CUCoreLib Releases](https://github.com/jimmyking9999999/CUCoreLib/releases)

> Make sure CUCoreLib is installed correctly in your BepInEx installation. CUCoreLib's documentation specifies that its DLL belongs in the `BepInEx/plugins/` folder. citeturn0view0

### Multiplayer

This mod also requires the **Multiplayer** mod.

For the required version, use:

- [Multiplayer v4.0.1](https://github.com/creaturefeaturelarry/casualties-together/releases/tag/v4.0.1)

## Installation

1. Install **BepInEx** according to the [Casualties Unknown modding guide](https://casualtiesunknown.miraheze.org/wiki/Modding).
2. Install **CUCoreLib**.
3. Install **Multiplayer v4.0.1**.
4. Install this mod by placing its files in the appropriate BepInEx mod directory.
5. Launch the game and verify that the mod loads correctly.
